# Polyglot Playground 🌍

A growing collection of tiny, useful programs written in different programming languages. Each folder is independent, beginner-friendly, and runnable from the terminal.

## Projects

| Language | Mini app | Run |
|---|---|---|
| Python | Password strength checker | `python3 python/password_checker.py` |
| JavaScript | Pomodoro timer | `node javascript/pomodoro.js` |
| TypeScript | Expense summary | `npx tsx typescript/expense_summary.ts` |
| Go | URL status checker | `go run go/url_checker.go https://example.com` |
| Rust | Word frequency counter | `rustc rust/word_counter.rs && ./word_counter` |
| Java | Unit converter | `javac java/UnitConverter.java && java -cp java UnitConverter` |
| C++ | Number guessing game | `g++ cpp/guess.cpp -o guess && ./guess` |
| C# | Habit streak calculator | `dotnet run --project csharp` |
| PHP | JSON formatter | `php php/json_formatter.php sample.json` |
| Ruby | Color palette generator | `ruby ruby/palette.rb` |
| Swift | Focus session planner | `swift swift/focus.swift` |
| Kotlin | Daily quote picker | `kotlinc kotlin/Quote.kt -include-runtime -d quote.jar && java -jar quote.jar` |

## Philosophy

Small enough to understand in minutes. Useful enough to keep. No frameworks unless a project genuinely needs one.

## Contributing

Add one focused project per language folder, include a run command, and keep dependencies minimal.
